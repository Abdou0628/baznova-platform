 1. PRÉSENTATION DU PROJET
════════════════════════════════════════════════════════════════════════════════

HireNova est une plateforme SaaS de recrutement propulsée par l'IA, conçue
pour le marché marocain et international. Elle comprend:

  - Générateur de CV IA (ATS-optimized)
  - Générateur de Lettres de Motivation IA
  - Analyse ATS (Applicant Tracking System)
  - Marché d'emploi (local + international)
  - Simulation d'entretien IA
  - Mobilité internationale (formatage CV/CL par pays)
  - Écosystème de 19 agents IA spécialisés
  - Chatbot IA avancé (3 modes: Conseil, Support, Produits)
  - Programme de parrainage
  - Campus HireNova Kit
  - Portail API pour développeurs
  - Dashboard employeur
  - Système anti-bot CAPTCHA intelligent
  - Mot de passe oublié (code 6 chiffres)
  - Tracking utilisateur + Admin analytics
  - Paiements: PayMob + Stripe
  - 4 langues: Français, Anglais, Arabe, Espagnol

Stack Technique:
  - Framework: Next.js 16 (App Router, TypeScript)
  - Styling: Tailwind CSS 4 + shadcn/ui (New York style)
  - Base de données: Prisma ORM + SQLite
  - Auth: NextAuth.js v4
  - State: Zustand (client) + TanStack Query (server)
  - Animations: Framer Motion
  - Charts: Recharts
  - Icons: Lucide React
  - AI: z-ai-web-dev-sdk
  - Toast: Sonner
  - Theme: next-themes

Statistiques du projet:
  - 113 commits git
  - 47 148 lignes de code source (TypeScript/TSX)
  - 87 composants React
  - 65+ API routes
  - 24 modèles Prisma
  - 4 langues supportées

════════════════════════════════════════════════════════════════════════════════
 5. FONCTIONNALITÉS ANTI-BOT - DÉTAIL TECHNIQUE
════════════════════════════════════════════════════════════════════════════════

COUCHE 1 - CAPTCHA Client (smart-captcha.tsx):
────────────────────────────────────────────
  Étapes:
  1. Génération défi mathématique aléatoire (a op b = ?)
  2. Opérations: addition (+), soustraction (-), multiplication (×)
  3. Collection signaux comportementaux:
     - Temps pour compléter le défi (timingScore)
     - Mouvements de souris (mouseScore)
     - Frappes clavier (keystrokeScore)
  4. Champ honeypot invisible (piège CSS, pas display:none)
  5. Timer 30 secondes, auto-régénération
  6. Max 3 tentatives, blocage après échec
  7. Génération token: btoa(JSON.stringify({
       ts: Date.now(),
       a: challenge.answer,
       fp: generateFingerprint()
     }))
  8. Transmission signaux + token au serveur

COUCHE 2 - Vérification Serveur (anti-bot.ts):
─────────────────────────────────────────────
  Checks séquentiels:
  1. validateCaptchaToken(token)
     - Décodage base64 JSON
     - Vérification âge < 5 minutes
     - Vérification réponse mathématique correcte

  2. checkHoneypot(honeypotValue)
     - Si rempli = bot direct → score 0

  3. validateEmailDomain(email)
     - 172 domaines jetables bloqués
     - Score réputation: 100 (gmail/outlook), 90 (corporate), 0 (jetable)

  4. checkIPVelocity(ip)
     - Max 3 inscriptions/IP/24h
     - Max 5 tentatives/IP/1h

  5. checkFingerprintVelocity(fingerprint)
     - Max 2 comptes/fingerprint/24h

  6. calculateVerificationScore(signaux)
     - Pondération finale:
       captcha: 25%
       email:   15%
       ip:      20%
       fingerprint: 15%
       behavior: 15%
       honeypot: 10%
     - Score < 20: BLOQUÉ
     - Score 20-39: FLAGGÉ (création avec alerte)
     - Score >= 40: AUTORISÉ

  7. assignTrackingId()
     - Format: HNV-XXXXXXX (31 caractères alphanumériques)
     - Identifiant unique pour chaque utilisateur

FLOW COMPLET INSCRIPTION:
──────────────────────────
  [Page Landing] → Click "Connexion" → Click "Créer mon compte"
    → [Smart CAPTCHA] Défi mathématique + signaux comportementaux
    → Vérification réponse → Token généré
    → [Formulaire] Nom, Email, Mot de passe
    → Submit → Pipeline anti-bot serveur (7 checks)
    → Score >= 40: Création compte + assignation trackingId
    → Redirection dashboard


════════════════════════════════════════════════════════════════════════════════
 6. FLOW MOT DE PASSE OUBLIÉ
════════════════════════════════════════════════════════════════════════════════

Étape 1 - Envoi du code:
  [Modal Connexion] → Click "Réinitialiser mon mot de passe"
    → Input email → Click "Envoyer le code de vérification"
    → API: POST /api/auth/send-reset-code
    → Vérification email existe en base
    → Génération code 6 chiffres
    → Stockage: globalThis.__resetCodeStore[email] = { code, expires }
    → Toast: "Code envoyé" ou "Aucun compte trouvé"

Étape 2 - Vérification du code:
  → Input code 6 chiffres → Click "Vérifier"
  → API: POST /api/auth/verify-reset-code
  → Vérification code correspond
  → Vérification expiration (< 5 min)
  → Passage à l'étape 3

Étape 3 - Nouveau mot de passe:
  → Input nouveau mot de passe
  → Input confirmation mot de passe
  → Click "Réinitialiser"
  → API: POST /api/auth/reset-password
  → Hash bcryptjs (12 rounds)
  → Mise à jour en base
  → Toast: "Mot de passe réinitialisé avec succès"
  → Retour à la connexion

Note: Ce flow est disponible pour TOUS les utilisateurs, sans restriction
de plan (abonné/gratuit).
