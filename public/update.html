Installation

  1. Telechargez les 7 fichiers ci-dessus
  2. Dans PowerShell, restaurez puis copiez :
    cd C:\Users\espacegamers\Desktop\HireNova; git checkout -- .
  3. Remplacez chaque fichier :
    Copy-Item "$HOME\Downloads\i18n.ts" "src\lib\i18n.ts" -Force
    Copy-Item "$HOME\Downloads\layout.tsx" "src\app\layout.tsx" -Force
    Copy-Item "$HOME\Downloads\auth-modal.tsx" "src\components\auth\auth-modal.tsx" -Force
    Copy-Item "$HOME\Downloads\manifest.ts" "src\app\manifest.ts" -Force
    Copy-Item "$HOME\Downloads\package.json" "package.json" -Force
    Copy-Item "$HOME\Downloads\route.ts" "src\app\api\auth\reset-password\route.ts" -Force
    Copy-Item "$HOME\Downloads\trusted-types.js" "public\trusted-types.js" -Force
  4. Relancez :
    taskkill /F /IM node.exe 2>$null; bun run dev
